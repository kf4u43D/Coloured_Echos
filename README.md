# Coloured_Echos

A stereo delay plug-in for Expert Sleepers disting NT, with 20 treatments covering analog, tube, tape, digital, multi-head, swept filters, reverse, ducking, auto-volume and looping. Shape repeats with tone, drive, modulation, CV and MIDI clock, or use the internal tempo.

Target: disting NT firmware 1.18.0 / API 13.

## Install

1. Download and extract the release archive.
2. Back up your current presets and plug-in files.
3. Copy `coloured_echos.o` to `/programs/plug-ins/` on the module's MicroSD card.
4. Safely eject the card, insert it into the module and restart.
5. Add **Coloured_Echos**, then choose a model and set Time, Feedback and Mix.

See [installation and controls](docs/INSTALL_NT.md) for routing, clock and modulation settings.
