# Coloured_Echos

A stereo delay collection for Expert Sleepers disting NT, with 20 treatments, eight multi-head patterns, reverse delay, ducking, auto-volume, a loop sampler, CV modulation and MIDI/CV clock synchronization.

Target: disting NT firmware 1.18.0 / API 13.

## Installation

Extract the archive and copy `coloured_echos.o` to `/programs/plug-ins/` on the module's MicroSD card. Safely eject the card, return it to the powered-off module and restart. Add **Coloured_Echos**, select a model, then adjust Time, Feedback and Mix.

Back up existing presets and plug-in files before replacing them. Keep a single copy of the plug-in in the plug-ins folder.

The archive includes [installation instructions](docs/INSTALL_NT.md), renderer profiles and file checksums. All supplied profiles use 45% Feedback.
